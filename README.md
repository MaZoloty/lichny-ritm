# Личный ритм

Мягкое мобильное PWA-приложение для личной системы: привычки, финансы,
накопления, цели, долги и сбережения. Модульное — пользователь сам выбирает,
что отслеживать.

Стек: **Next.js 15 (App Router) · TypeScript · Tailwind CSS · Supabase (Auth + PostgreSQL + RLS)**.

## Как запустить (по шагам)

### 1. Создать проект в Supabase

1. Зайти на [supabase.com](https://supabase.com) → **New project**.
2. Дождаться создания базы (1–2 минуты).
3. Открыть **SQL Editor** → **New query**.
4. Скопировать туда **весь** файл [`supabase/schema.sql`](supabase/schema.sql)
   и нажать **Run**. Это создаст все таблицы, политики безопасности и
   авто-создание профиля при регистрации.

### 2. Подставить ключи

1. В Supabase: **Project Settings → API**.
2. Скопировать **Project URL** и **anon public** ключ.
3. Открыть файл `.env.local` в папке проекта и заменить заглушки:

   ```
   NEXT_PUBLIC_SUPABASE_URL=https://твой-проект.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=твой-anon-ключ
   ```

> Файл `.env.local` уже создан с заглушками. Просто замени значения.

### 3. Запустить локально

```bash
npm install      # один раз
npm run dev      # запуск
```

Открыть на телефоне или в браузере: **http://localhost:3000**

### 4. Проверить, что всё работает

- Зарегистрироваться (почта + пароль не короче 6 символов).
- Пройти онбординг, выбрать 1–2 модуля.
- Убедиться, что на главной и в меню появились только выбранные разделы.
- В настройках включить/выключить модуль — меню обновится.

> Если в Supabase включено подтверждение почты (**Authentication → Providers →
> Email → Confirm email**), после регистрации нужно подтвердить письмо.
> Для быстрого старта это подтверждение можно временно выключить.

## Deploy to Vercel

Перед деплоем код должен быть в GitHub-репозитории, а `supabase/schema.sql` уже должен быть применён в Supabase SQL Editor.

1. В Vercel создай новый проект из GitHub-репозитория.
2. Framework Preset: **Next.js**.
3. Build Command: `npm run build`.
4. Install Command: `npm install`.
5. Output Directory оставь пустым / default.

В **Vercel → Project Settings → Environment Variables** добавь:

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project-ref.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-publishable-or-anon-public-key
```

Эти значения должны совпадать с Supabase Project URL и publishable/anon public key. Не добавляй в клиентский проект `service_role`, database password, JWT secret или SMTP secrets.

После первого деплоя скопируй production URL из Vercel, например:

```text
https://your-project.vercel.app
```

Затем в Supabase открой **Authentication → URL Configuration** и добавь:

- **Site URL**: production URL из Vercel.
- **Redirect URLs**:
  - `https://your-project.vercel.app`
  - `https://your-project.vercel.app/**`

Если используешь preview-деплои Vercel, добавь также preview redirect pattern, например:

```text
https://*.vercel.app/**
```

Для production-сборки не нужен `.env.local` в репозитории: локальный файл игнорируется Git, а Vercel читает значения из Environment Variables.

  auth/signout/           выход
src/
  lib/supabase/           клиенты Supabase (браузер/сервер/middleware)

  lib/habits.ts           логика привычек: проценты, статусы, стрики

  lib/finance-data.ts     загрузка операций и аналитики за период
  lib/categories.ts       стартовые категории + сидер
  components/             BottomNav, Modal, переключатели, формы
  components/habits/       HabitsClient, GoalsModal, HabitFormModal
  components/finance/      FinanceClient, TransactionModal, *Manager
  types/db.ts             типы таблиц

public/manifest.json      PWA-манифест
public/icons/             иконки приложения
middleware.ts             обновление сессии Supabase
